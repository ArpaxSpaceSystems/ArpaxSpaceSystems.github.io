Launch visualization of the website in local
===

To launch local server to see changes when code is updated, go in the repository of the website (here ArpaxSpaceSystems.github.io) and open a shell window (cmd in the path entry) and launch the following python command :

``` python -m http.server 8000 ```

Then go to your navigator and go to [http://localhost:8000](http://localhost:8000)

To obeserve changes between two sames, refresh the page.

To end session use ``` CTRL + C ``` in the command shell.
